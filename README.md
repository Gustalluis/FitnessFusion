# FitnessFusion
Uma API RESTful moderna e segura para a gestão completa de academias (envolvendo clientes, planos, funcionários e inscrições). O projeto é desenvolvido com PHP 8.3, Laravel, PostgreSQL (via Docker) e Eloquent ORM, com forte ênfase em arquitetura limpa, boas práticas de backend, controle de acesso e segurança robusta.
